# 연간 대회 달력

> **상태: Phase 4에서 본격 생성.** 약 500개 대회의 `게임내_개최일` 규칙을 실제 게임 내 날짜로 전개한다.

## 운영 방식(예정)

- 각 대회의 `개최_주기`/`게임내_개최일` 문자열 규칙을 받아, 주어진 연도(예: 2035)의 실제 날짜로 펼친 색인을 만든다.
- GM은 현재 `게임내_날짜` 기준으로 **다가오는 대회**를 조회해 플레이어에게 안내한다.
- 출전 자격(명성·랭킹·선행대회 입상·면허 등급·플래그)을 검사한 뒤 출전 가능 여부를 판정한다.

## 색인 형식(예정)

```json
{
  "연도": 2035,
  "이벤트": [
    { "날짜": {"월":6,"일":21}, "대회_id":"JP-TYO-L-007", "티어":"로컬", "도시":"도쿄" }
  ]
}
```

## 시즌 구조(초안)

- 상시: 로컬 대회(매월/격주).
- 분기: 지방 대회.
- 연 1회 집중기: 국가 대회 시즌(가을), 대륙 대회(겨울).
- 세계 대회: 연 1회 또는 격년의 정점 이벤트. 자격은 대륙 대회 상위 입상에서 이어진다.
