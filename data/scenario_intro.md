# 시작 시나리오 — 입문 (GM 진행 대본)

> `saves/player.json`이 **없을 때** GM이 진행하는 도입부. 끝에서 첫 세이브를 생성한다.
> 톤: 다큐멘터리적 사실성 + 모험(lore.md). 자유 입력을 존중하되 아래 비트는 반드시 거친다.

## 비트 1 — 오프닝 (이름·출신지)

- 2035년 어느 도시의 아침. 거리 풍경·뉴스로 "포켓몬이 일상이 된 현실"을 1~2문단으로 보여준다.
- 플레이어에게 **이름**과 **출신지(국가·도시)**를 자유 입력으로 받는다. 도시는 `data/regions.md` 권역과 느슨히 연결.
- 출신지를 못 정하면 도쿄(일본 수도권)를 기본 제안.

## 비트 2 — 멘토와 첫 만남

- `data/npcs/mentors.json`의 **사카모토 렌**(또는 출신지에 맞는 멘토)을 등장시킨다.
- 면허 발급의 의미, 포켓몬 센터 사용법(회복·박스·대회 접수), 이 세계의 규칙을 대사로 자연스럽게 전달.

## 비트 3 — 스타터 획득 (지역 생태와 일관되게)

- **완전 임의가 아니라** 출신지 기후·지리에 어울리는 후보 3종을 멘토/센터가 제시한다.
- 기본 제안 표(GM이 출신지에 맞게 조정 가능):

| 출신지 유형 | 스타터 후보(예) |
|---|---|
| 온대 대도시(도쿄·서울·런던 등) | 파이리(4) / 꼬부기(7) / 이상해씨(1) |
| 해안·항구 | 꼬부기(7) / 잉어킹(129) / 고라파덕(54) |
| 화산·고온 | 파이리(4) / 마그마그(218) / 디그다(50) |
| 극지·고산 | 셀러(86) / 눈꼬마(361) / 단단지(213) |
| 우림·삼림 | 이상해씨(1) / 캐터피(10) / 나무지기(252) |
| 사막·협곡 | 모래두지(27) / 롱스톤(95) / 고우스트 계열 회피 |

- 스타터는 보통 **레벨 5**, IV는 `randint(0,31)`×6, 성격은 25종 중 `randint`로 확정(세이브에 기록).
- 라이벌 **유진**(`rivals.json`)이 등장해 **상성상 까다로운 스타터**(플레이어가 불꽃→유진 물, 물→풀, 풀→불꽃)를 고른다.

## 비트 4 — 튜토리얼 전투

- 라이벌 유진(성장단계1) 또는 약한 야생과 1회 전투. `mechanics/battle.md` 규칙 + 수치 투명성을 체험시킨다.
- 첫 전투 시 세이브 `rng.seed`를 확정(예: 현재 실제시각 기반 정수)하고 `rng.counter=0`에서 시작.

## 비트 5 — 첫 목표 제시

- `data/calendar_2035.json`에서 출신지 인근의 가장 가까운 **로컬 신인배**를 찾아 안내(자격: 면허만 있으면 OK).
- 한지윤 박사(`mentors.json`)를 소개하거나 연락처를 주어 **도감** 동기를 부여(선택).

## 비트 6 — 첫 세이브 생성

- 위 내용을 반영해 `saves/SCHEMA.md` 형식으로 `saves/player.json`을 생성한다:
  - 플레이어 이름/출신지, 현재_위치(출신지 센터), 게임내_날짜(2035-06-01 아침 기본),
    파티[스타터 1마리], 인벤토리(몬스터볼5·상처약3), 소지금(현지 통화 환산 30000엔 상당),
    스토리_플래그(["튜토리얼_완료","스타터_획득","멘토_사카모토_만남","라이벌_유진_만남"]),
    현재_퀘스트(가까운 로컬 신인배 출전 준비).
- 생성 후 "이제 ‘이어하기’라고 하면 여기서 계속됩니다"라고 안내.
