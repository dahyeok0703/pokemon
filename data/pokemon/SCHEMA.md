# 포켓몬 종 데이터 스키마 (data/pokemon/)

> 종(species) 데이터는 **사실 데이터**(종족값·타입·기술풀)로, 가능하면 PokéAPI 캐싱으로 만든다.
> 현재 환경은 PokéAPI 접근이 막혀 있다(HTTP 403). → 대표 세트부터 생성 후 점진 확장(Phase 2).
> **절대 손으로 한 줄씩 1000마리를 적지 않는다.** 스키마 + 생성 스크립트(`tools/`)로 만든다.

## 저장 형식

- 세대/타입별로 분할된 JSON 파일에 종 객체 배열을 담는다. 예: `data/pokemon/gen1.json`, `gen2.json`, …, `legendary.json`.
- `data/pokemon/index.json`에 `{ id → {이름_한, 파일, 타입[] } }` 경량 색인을 둬서, GM이 전체를 로드하지 않고 필요한 종만 찾게 한다.

## 종 객체 스키마

```json
{
  "id": 6,                          // 전국도감 번호(정수). 폼 구분은 form 필드로.
  "form": "기본",                    // "기본" | "메가" | "거다이맥스" | "리전폼(알로라)" 등
  "이름": { "한": "리자몽", "영": "Charizard" },
  "분류": "화염 포켓몬",
  "타입": ["불꽃", "비행"],          // 1~2개. 타입명은 mechanics/battle.md의 타입표와 일치.
  "종족값": { "HP": 78, "공격": 84, "방어": 78, "특공": 109, "특방": 85, "스피드": 100 },
  "특성": ["맹화"],                  // 일반 특성
  "숨겨진특성": "태양의힘",          // 없으면 null
  "기술풀": [                        // 학습 가능 기술 목록
    { "기술": "플레어드라이브", "방식": "레벨업", "레벨": 50 },
    { "기술": "에어슬래시",     "방식": "레벨업", "레벨": 36 },
    { "기술": "지진",           "방식": "기술머신" }
  ],
  "진화": {                          // 진화 트리(이 종 기준). 없으면 null
    "from": { "id": 5, "이름": "리자드" },
    "조건": { "방식": "레벨", "값": 36 },     // 방식: 레벨|돌|교환|친밀도|장소|기타
    "to": []                          // 더 진화 없으면 빈 배열
  },
  "현실_출현지역": ["일본 화산지대", "이탈리아 시칠리아", "하와이"],  // regions.md의 키와 연결
  "서식_환경": "화산·건조 고온지대",
  "희귀도": "희귀",                  // 흔함 | 보통 | 희귀 | 매우희귀 | 전설 | 환상
  "메가진화_가능여부": true,         // true면 mega.md에 해당 폼 데이터 존재
  "거다이맥스_가능여부": false,      // true면 gigantamax.md에 해당 폼 데이터 존재
  "기본경험치": 240,                 // 격파 시 경험치 계산용(base exp)
  "경험치그룹": "중속",              // 빠름|중속|중간|느림|… (training.md의 누적표와 연결)
  "포획률": 45,                      // 0~255, catching.md 공식 입력
  "성별비": { "수": 87.5, "암": 12.5 },  // 무성이면 {"무성": 100}
  "플레이버": "한 번 타오른 꼬리의 불꽃은 비를 맞아도 쉽게 꺼지지 않는다."
}
```

## 규칙

- `타입` 문자열은 반드시 `mechanics/battle.md`의 타입 상성표 키와 동일해야 한다.
- `메가진화_가능여부`/`거다이맥스_가능여부`가 true인 종만 해당 강화가 가능. 폼 상세(강화 후 종족값/타입/특성/전용기)는 `mechanics/mega.md`·`mechanics/gigantamax.md`에 둔다.
- 전설/환상은 `희귀도`로 표시하고 포획·등장에 규제(법·시나리오 조건)를 건다.
- **개체(individual)** 데이터(IV/EV/성격/현재레벨/현재기술/개체별 별명 등)는 종 데이터가 아니라 **세이브**(`saves/player.json`)에 저장한다. 종 데이터는 불변 사실만 담는다.
