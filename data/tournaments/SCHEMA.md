# 대회 데이터 스키마 (data/tournaments/)

> 약 500개의 대회를 만든다. **손으로 적지 않고** 티어별 템플릿 + 생성 스크립트(`tools/`)로 만든다(Phase 4).
> 티어별로 파일을 분할: `local.json`(~250), `regional.json`(~120), `national.json`(~70),
> `continental.json`(~40), `world.json`(~10), `special.json`(~30). 합계 ≈ 500.
> `data/tournaments/index.json`에 `{ id → {이름, 티어, 게임내_개최일, 자격요약} }` 경량 색인을 둔다.

## 대회 객체 스키마

```json
{
  "id": "JP-TYO-L-007",             // 고유 ID. 권장: 국가-도시-티어-번호
  "이름": "도쿄 시타마치 신인배",
  "티어": "로컬",                    // 로컬 | 지방 | 국가 | 대륙 | 세계 | 특수
  "주최주체": {                      // 지자체|기업|인물|단체
    "유형": "지자체",
    "이름": "도쿄도 다이토구"
  },
  "현실_개최지": { "국가": "일본", "도시": "도쿄", "장소": "다이토 구민 배틀돔" },
  "개최_주기": "매월",               // 매월|분기|반기|연1회|격년|4년마다|단발
  "게임내_개최일": ["매월 셋째 주 토요일"],  // calendar.md가 이 규칙으로 실제 날짜를 배치
  "출전_자격": {                     // 모든 조건을 AND로 검사
    "최소_명성": 0,
    "최소_랭킹": null,               // null이면 무관
    "선행대회_입상": [],             // 예: [{"id":"JP-TYO-L-003","최소순위":4}]
    "면허_등급": "신인",             // 신인|정규|상급|마스터
    "기타_플래그": []                // 세이브 스토리 플래그 요구(예: "지역추천장")
  },
  "포맷": {
    "방식": "싱글",                  // 싱글|더블
    "파티수": 3,                     // 출전 등록 마릿수
    "출전수": 3,                     // 한 경기 사용 마릿수(예: 3vs3)
    "교체": "허용"                   // 허용|금지
  },
  "특수룰": {                        // 없으면 각 항목 기본값
    "레벨캡": 50,                    // null이면 무제한, 숫자면 그 레벨로 보정/상한
    "타입제한": null,                // 예: "물 타입만" / "단일타입파티"
    "전설_금지": true,
    "환상_금지": true,
    "메가_금지": false,
    "거다이맥스_금지": false,
    "아이템_금지": false,
    "동일종_금지": true,             // 같은 종 중복 금지
    "기타": []
  },
  "라운드_구조": {                   // 토너먼트 구성
    "방식": "싱글엘리미네이션",       // 싱글엘리미네이션|더블엘리미네이션|스위스|리그|예선+본선
    "참가_규모": 16,
    "라운드": ["32강 예선", "16강", "8강", "4강", "결승"]
  },
  "상금": { "통화": "JPY", "우승": 50000, "준우승": 20000, "4강": 8000 },
  "보상_아이템": [ { "순위": "우승", "아이템": "메가스톤 조각", "수량": 1 } ],
  "명성_점수": { "우승": 50, "준우승": 25, "본선진출": 5 },
  "다음_단계": ["JP-KNT-R-002"],     // 이 대회 입상이 자격이 되는 상위 대회(성장 경로)

```

## 규칙

- **성장 경로**: `다음_단계`와 상위 대회의 `출전_자격.선행대회_입상`이 서로 맞물리도록 생성한다. 큰 대회일수록 자격이 까다롭다.
- `게임내_개최일`은 사람이 읽는 규칙 문자열로 두고, `data/calendar.md`가 이를 실제 게임 내 날짜로 전개한다.
- 모든 `현실_개최지`는 **실제 지명**을 쓴다.
- 특수 대회(`특수` 티어)는 기업배·인물배·테마배 등 개성 있는 `특수룰`을 가진다(예: "단일타입", "메가 전원 의무", "노 아이템").
- 티어별 권장 분포(합계 ≈ 500): 로컬 250 / 지방 120 / 국가 70 / 대륙 40 / 세계 10 / 특수 30.
