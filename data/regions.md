# 현실 지리 ↔ 포켓몬 출현 매핑

> 포켓몬 종 데이터의 `현실_출현지역`(실제 지명)과 `서식_환경`은 **타입 기반 휴리스틱**으로 시드되어 있다
> (`tools/build_pokemon.py`의 `TYPE_REGION` 표). 이 문서는 그 매핑 원칙과 **권역(region) 키**를 정의해,
> GM이 "지금 위치 → 출현 가능 종"을 판정하고 종별 출현지를 정교화하는 기준으로 삼는다.

## 매핑 원칙

타입 → 실제 지구의 기후·지형·문화와 연결한다(생태적 일관성). 전설/환상은 그 지역의 신화·역사와 엮는다.

| 타입 | 대표 실제 지역 | 서식 환경 |
|---|---|---|
| 불꽃 | 이탈리아 시칠리아(에트나), 하와이, 인도네시아, 사하라 | 화산·고온 건조지대 |
| 물 | 지중해 연안, 동남아 군도, 노르웨이 피오르, 아마존 | 해안·하천·호수 |
| 풀 | 아마존, 콩고분지, 동남아 정글, 뉴질랜드 | 우림·삼림·초원 |
| 전기 | 도쿄 수도권, 독일 루르, 디트로이트, 상하이 | 대도시·산업지대 |
| 얼음 | 시베리아, 그린란드, 알프스, 안데스 고지 | 극지·고산 |

| 고스트 | 트란실바니아, 프라하 고성, 교토 폐사, 뉴올리언스 | 폐허·묘지·고성 |

> 특정 종의 출현지를 더 정교화하려면 해당 종 JSON의 `현실_출현지역`을 직접 손봐도 된다(데이터가 진실).

## 권역 키 (거점 도시 기준)

GM이 플레이어 위치를 다룰 때 쓰는 권역. 각 권역은 기후·주요 타입·거점 도시를 가진다.

```json
{
  "키": "JP-수도권",
  "이름": "일본 수도권",
  "국가": "일본",
  "기후": "온대 습윤",
  "지형": ["대도시", "만", "근교 산지"],
  "주요_타입": ["전기", "노말", "에스퍼", "강철"],
  "거점도시": ["도쿄", "요코하마", "지바"],
  "전설_연계": []
}
```

초기 권역 예시(필요 시 확장):
- `JP-수도권`(도쿄권) · `JP-화산지대`(가고시마·벳푸) · `EU-알프스`(취리히·인스브루크)
- `NA-캐니언`(라스베이거스·플래그스태프) · `SA-안데스`(쿠스코·라파스) · `AF-사하라`(카이로·마라케시)
- `OC-아웃백`(앨리스스프링스) · `AS-히말라야`(카트만두) · `ARC-극지`(롱이어비엔)

## 이동 규칙 (Phase 3에서 수치 확정)

- 도시 내: 시간대 1~2단위 소비.
- 국내(권역 내/인접): 0.5~2일.
- 국제(권역 간): 항공 일수 + 시차·기후 적응 묘사. 게임 내 날짜를 소비하며 대회 달력과 맞물린다.
- 전설은 권역의 `전설_연계`와 시나리오 플래그가 충족될 때만 조우 가능.
