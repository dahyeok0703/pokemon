# 현실 지리 ↔ 포켓몬 출현 매핑

> **상태: Phase 2에서 본격 작성.** 아래는 매핑 원칙과 스키마 골격이다.
> 포켓몬 종 데이터의 `현실_출현지역` 키와 여기 정의되는 지역 키가 연결된다.

## 매핑 원칙

- 타입·생태·기후·문화로 분포를 정한다.
  - 빙설/얼음 → 극지·고산(시베리아, 알프스, 안데스 고지, 그린란드 등)
  - 물 → 해안·하천·호수·습지(지중해 연안, 아마존, 동남아 군도 등)
  - 불꽃 → 화산·사막(이탈리아 화산지대, 사하라, 하와이, 인도네시아 등)
  - 풀/벌레 → 우림·삼림(아마존, 콩고분지, 동남아 정글)
  - 바위/땅 → 협곡·광산·고원(그랜드캐니언, 안데스, 호주 아웃백)
  - 강철/전기 → 산업도시·대도시(루르, 도쿄권, 디트로이트 등)
  - 고스트/에스퍼/악 → 역사·종교·신화의 장소(고대 유적, 묘지, 사원)
- **전설/환상**은 그 지역의 신화·지형·역사와 엮는다(예: 북유럽 신화권, 이집트 유적, 안데스 잉카 전승 등).
- 이동에는 거리·교통·시차·기후가 작용한다(아래 이동 규칙).

## 지역 객체 스키마(예정)

```json
{
  "키": "JP-화산지대",
  "이름": "일본 화산지대",
  "국가": "일본",
  "기후": "온대·화산성",
  "지형": ["화산", "온천", "산악"],
  "주요_타입": ["불꽃", "바위", "땅"],
  "대표_출현종": [/* 종 id */],
  "전설_연계": [/* 전설 종 id + 전승 메모 */],
  "거점도시": ["가고시마", "벳푸"],
  "이동": { "인접지역": [], "표준_이동시간": {} }
}
```

## 이동 규칙(예정, Phase 2/3에서 수치화)

- 도시 내 이동: 시간대 1~2단위.
- 국내 이동: 거리·교통수단에 따라 0.5~2일.
- 국제 이동: 항공 기준 일수 + 시차/기후 적응 묘사.
- 이동은 게임 내 날짜를 소비하고, 대회 달력과 맞물린다.
