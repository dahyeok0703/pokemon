# 거다이맥스 규칙

> **상태: Phase 3에서 가능 종 폼 데이터 작성.** 아래는 확정 규칙.
> 주의: 이 게임에는 **일반 다이맥스가 없다.** 오직 거다이맥스만 존재한다(가능 종 한정).

## 발동 조건

- 거다이맥스 가능 종에 한함(종 데이터 `거다이맥스_가능여부: true`).
- **배틀당 1회**. 세이브 `현재_전투.거다이맥스_사용`으로 추적.
- 발동 시 **지정 턴(기본 3턴)** 동안 거대화 상태 유지 후 원래대로.

## 효과

- HP 최대치 **1.5~2배 보정**(종/폼별 계수, 발동 시 현재HP도 비율 적용).
- 일반 기술이 **거다이맥스 전용기(G-Max기)**로 치환(폼별 전용기 데이터).
- 지정 턴 종료 시 보정 HP 해제(초과분 소멸 규칙은 Phase 3에서 확정).

## 폼 데이터 형식(예정)

```json
{ "기반_id": 6, "form": "거다이맥스",
  "HP배율": 1.8, "전용기": { "불꽃": "다이맥스파이어볼" } }
```

## 제약

- 메가진화와 **동시 사용 불가**. 강화 메커니즘은 메가·거다이맥스 둘뿐.
