# 전투 규칙 — 결정론적 수치 계산

> **상태: Phase 3에서 완성**(타입 상성표 전체, 상태이상 수치, 우선도표, 날씨/필드, 검증).
> 아래 공식은 확정 골격이다. GM은 감으로 판정하지 않고 이 공식 + 시드 PRNG(CLAUDE.md 3절)로 계산한다.

## 능력치 산출

- HP = `floor((2·종족값 + IV + floor(EV/4))·레벨/100) + 레벨 + 10`
- 그 외 = `floor( (floor((2·종족값 + IV + floor(EV/4))·레벨/100) + 5) · 성격보정 )`
  - 성격보정: 상승 1.1 / 하강 0.9 / 무관 1.0 (성격표는 training.md)

## 데미지 공식 (단계별 floor 엄수)

```
기본 = floor( floor( floor( (2·레벨/5 + 2) · 위력 · A/D ) / 50 ) + 2 )
최종 = floor( 기본 · 변동 · 자속 · 타입상성 · 급소 · 화상 · 기타 )
```
- A/D: 물리=공격/방어, 특수=특공/특방. 랭크(-6~+6) 반영.
- 변동: `randint(85,100)/100` (매 타격).
- 자속: 1.5 (사용자 타입과 기술 타입 일치 시).
- 타입상성: 0 / 0.25 / 0.5 / 1 / 2 / 4 (상성표는 Phase 3에서 전체 데이터화).
- 급소: 1.5 (발동 시). 화상: 물리기 0.5 (화상 상태 공격자).

## 확률 판정 (난수 노출)

- 명중: `유효명중 = 기술명중 · 명중랭크보정 · 회피랭크보정`. `randint(0,99) < 유효명중`이면 적중.
- 급소: 단계별 확률(기본 약 1/24). 추가효과·풀죽음·연속기 횟수·상태이상 발동/회복 전부 수치.
- 모든 굴림은 PRNG(seed,counter)로 굴리고 counter를 증가시켜 세이브에 기록 → 재현 가능.

## 행동 순서

우선도(-7~+5) → 스피드(랭크·도구·마비·날씨 반영) → 동속이면 난수.

## 상태이상·날씨·필드

- 독(매턴 1/8), 맹독(누적), 화상(매턴 1/16 + 물리 0.5), 마비(스피드↓ + 행동불가 확률), 잠듦(행동불가 + 잔여턴), 얼음(행동불가 + 해동 확률) — 정확한 수치는 Phase 3에서 확정.
