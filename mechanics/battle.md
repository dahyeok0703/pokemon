# 전투 규칙 — 결정론적 수치 계산 (확정)

> GM은 감으로 판정하지 않는다. 모든 결과는 이 공식 + 시드 PRNG(CLAUDE.md 3절)로 계산한다.
> **데이터원**: 타입 상성 `data/type_chart.json`, 성격 `data/natures.json`, 기술 `data/pokemon/moves.json`,
> 강화 폼 `data/pokemon/forms.json`. 참조 구현·검증: `tools/verify_battle.py`(전부 통과 확인).

## 1. 능력치 산출

```
core = (2·종족값 + IV + floor(EV/4)) · 레벨  // 100      (정수 나눗셈)
HP   = core + 레벨 + 10
그외  = floor( (core + 5) · 성격보정 )
```
- IV 0~31, EV 0~252(합 ≤510). 성격보정: 상승 1.1 / 하강 0.9 / 무관 1.0 (`data/natures.json`).
- 검증 예: 리자몽 Lv50 고집 IV31 → HP153, 공격149(+), 특공116(-).

## 2. 데미지 공식 (단계별 floor 엄수)

```
기본 = floor( floor( floor( (2·레벨/5 + 2) · 위력 · A/D ) / 50 ) + 2 )
최종 = floor( 기본 · 변동 · 자속 · 타입상성 · 급소 · 화상 · 기타 )
```
- A/D: 물리=공격/방어, 특수=특공/특방. **랭크 변화 반영 후의 실효 능력치** 사용.
- 변동 = `randint(85,100)/100` (매 타격, PRNG 1회 소비).
- 자속 = 1.5 (사용자 타입에 기술 타입 포함 시).
- 타입상성 = `data/type_chart.json` 곱(0 / 0.5 / 1 / 2; 듀얼은 곱연산 → 0/0.25/0.5/1/2/4).
- 급소 = 1.5 (발동 시). 화상 = 0.5 (화상 상태가 물리기 사용 시).
- 기타 = 날씨/도구/특성 등 추가 보정.

## 3. 랭크 보정 (-6 ~ +6)

- 공격·방어·특공·특방·스피드: `stage≥0 → (2+stage)/2`, `stage<0 → 2/(2-stage)`.
- 명중·회피: `stage≥0 → (3+stage)/3`, `stage<0 → 3/(3-stage)`.

## 4. 확률 판정 (난수 노출 필수)

- **명중**: `유효명중 = 기술명중 · (명중랭크/회피랭크 보정)`. `randint(0,99) < 유효명중`이면 적중. (기술 명중이 `null`이면 필중).
- **급소 단계 확률**: 0단계 1/24, 1단계 1/8, 2단계 1/2, 3단계+ 1/1. `rand() < 확률`이면 급소.
- 추가효과: 기술 `추가효과확률` 로 `randint(0,99) < 확률` 판정.
- 풀죽음·연속기 횟수·상태이상 부여/회복도 전부 `rand()`로 판정하고 **counter 증가분을 세이브에 반영**.

## 5. 행동 순서

`우선도(-7~+5)` 큰 쪽 먼저 → 같으면 `실효 스피드`(랭크·마비·도구·날씨 반영) 큰 쪽 → 동일하면 `rand()` 동전던지기.

## 6. 상태이상 (턴 종료/행동 시 수치)

| 상태 | 효과 |
|---|---|
| 독 | 매 턴 종료 시 최대HP의 **1/8** 감소 |
| 맹독 | 매 턴 **n/16** 감소(n=경과턴, 1부터 누적 증가) |
| 화상 | 매 턴 **1/16** 감소 + 물리 데미지 **×0.5** |
| 마비 | 실효 스피드 **×0.5** + 행동 시 **25%** 확률로 행동불가 |
| 잠듦 | 행동불가, 잔여턴 `randint(1,3)`. 매 턴 감소, 0이면 기상 |
| 얼음 | 행동불가, 매 턴 **20%** 해동(`rand()<0.2`). 불꽃 기술 피격 시 즉시 해동 |

> 한 개체는 주 상태이상 1개만(혼란·풀죽음 등은 별도 휘발성 상태로 중첩 가능).

## 7. 날씨·필드

| 날씨 | 효과 |
|---|---|
| 쾌청 | 불꽃 ×1.5, 물 ×0.5 |
| 비 | 물 ×1.5, 불꽃 ×0.5 |
| 모래바람 | 바위 타입 특방 ×1.5; 바위/땅/강철 외 매 턴 1/16 감소 |
| 싸라기눈/눈 | 얼음 타입 방어 ×1.5(눈) 또는 비얼음 1/16 감소(싸라기) — 채택안: **눈**(방어 보정) |

지속 5턴(도구 시 8턴). 필드(그래스/일렉트릭 등)는 도입 시 본 절에 수치 추가.

## 8. 강화

- 메가진화: `mechanics/mega.md`. 거다이맥스: `mechanics/gigantamax.md`. **각 배틀당 1회**, 동시 불가.
- 강화 폼의 종족값/타입/특성은 `data/pokemon/forms.json`에서 조회해 능력치 재계산.

## 9. 출력 투명성 (필수)

매 행동마다 계산 근거를 보여준다:
```
리자몽 → 플레어드라이브(위력120/물리)
명중: 굴림07 < 100 → 적중
변동0.87 · 자속1.5 · 상성2.0(풀×2/독×1) · 급소없음 → 227 데미지
이상해꽃 HP 168 → 0  (기절)
반동 0.33×227 = 74 → 리자몽 HP 153 → 79
```
난수로 갈린 부분(명중/급소/추가효과/풀죽음 등)은 **굴림 값**을 표시한다.
