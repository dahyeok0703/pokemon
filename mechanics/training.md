# 육성 규칙 — 레벨·경험치·EV/IV·성격·진화

> **상태: Phase 3에서 완성·검증.** 아래는 확정 골격.

## 경험치·레벨업

- 누적 경험치표는 경험치 그룹별(빠름/중속/중간/느림/변칙/고속변칙)로 정의.
- 격파 시 획득 경험치(본가형):
  ```
  exp = floor( (기본경험치 · 상대레벨 / 5) · 보정 )
  ```
  - 보정: 교환개체·악세사리·전투참여수 등(Phase 3에서 확정).

## 개체값 IV / 노력치 EV

- IV: 각 능력치 0~31. 개체 생성 시 확정(야생은 난수, NPC는 데이터 지정).
- EV: 각 능력치 0~252, 합계 ≤ 510. 격파/특훈으로 적립.
- 능력치 반영 공식은 `mechanics/battle.md`.

## 성격(25종) 보정표

- 각 성격은 한 능력치 +10%, 한 능력치 -10%(같으면 무보정). 표는 Phase 3에서 전체 기입.

## 진화

- 조건: 레벨 / 돌 / 교환 / 친밀도 / 장소 / 시간 / 기타. 종 데이터 `진화.조건`을 따른다.
- 진화 시 개체_uid는 유지하고 종_id/별명 기본값 갱신, 능력치 재계산.
