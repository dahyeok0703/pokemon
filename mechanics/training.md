# 육성 규칙 — 레벨·경험치·EV/IV·성격·진화 (확정)

> 데이터원: 경험치표 `data/exp_tables.json`(그룹별 Lv1~100 누적), 성격 `data/natures.json`.

## 경험치·레벨업

- 누적 경험치표는 종의 `경험치그룹`(빠름/중간/느림/중속/변칙(저속후고속)/변칙(고속후저속))으로 `data/exp_tables.json`에서 조회.
  - 인덱스 0 = 레벨1(0), 인덱스 n-1 = 레벨n 누적 경험치. (검증: 중속 Lv100=1,059,860, 느림 Lv50=156,250)
- 격파 시 획득:
  ```
  exp = floor( 기본경험치 · 상대레벨 / 5 · 보정 )
  ```
  - 기본경험치 = 종 데이터 `기본경험치`. 보정 = 교환개체 1.5·학습장치·전투참여 분배 등(적용 시 명시).
- 누적 경험치가 다음 레벨 임계 이상이면 레벨업 → 능력치 재계산(battle.md 1절), 레벨업 기술 습득 체크.

## IV / EV

- IV: 능력치별 0~31. 생성 시 확정(야생 난수, NPC 데이터 지정).
- EV: 능력치별 0~252, 합계 ≤ 510. 격파/특훈으로 적립. 4EV당 실능력치 영향(공식의 `floor(EV/4)`).

## 성격 (25종)

- `data/natures.json`: 각 성격 `{상승, 하강}`(상승 ×1.1, 하강 ×0.9, 무관 ×1.0). HP에는 성격보정 없음.

## 진화

- 종 데이터 `진화.조건`(레벨/돌·도구/교환/친밀도/장소/기술습득/시간대 등)을 따른다.
- 진화 시 `개체_uid` 유지, `종_id`/기본 `별명` 갱신, 능력치 재계산, 진화 후 종의 기술풀 반영.
- 친밀도 진화는 세이브 개체 `친밀도`(0~255) 임계 이상에서 레벨업 시 발동.
