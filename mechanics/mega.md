# 메가진화 규칙

> **상태: Phase 3에서 가능 종 폼 데이터 작성.** 아래는 확정 규칙.

## 발동 조건

- 대응 종 + 전용 **메가스톤**을 지닌도구로 장착. (종 데이터 `메가진화_가능여부: true`)
- **배틀당 1회**. 세이브 `현재_전투.메가_사용`으로 추적.
- 발동 선언은 그 턴 행동 전에. 발동 후 그 전투 동안 메가 폼 유지(기절·전투종료 시 해제).

## 효과

- 메가 폼의 **종족값·타입·특성**으로 교체(폼별 데이터는 본 파일의 폼 테이블에 정의).
- 능력치는 메가 종족값으로 재계산(IV/EV/레벨/성격 그대로 적용).

## 폼 데이터 형식(예정)

```json
{ "기반_id": 6, "form": "메가", "변종": "X",
  "종족값": {...}, "타입": ["불꽃","드래곤"], "특성": "단단한발톱" }
```

## 제약

- 거다이맥스와 **동시 사용 불가**(한 개체가 한 전투에서 하나의 강화만). 강화 메커니즘은 메가·거다이맥스 둘뿐.
