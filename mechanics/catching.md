# 포획 규칙 (확정)

> 참조 구현·검증: `tools/verify_battle.py`(통과). 모든 굴림은 PRNG(seed,counter)로 재현 가능.

## 포획률 a

```
a = floor( (3·최대HP − 2·현재HP) · 종포획률 · 볼보정 · 상태보정 / (3·최대HP) )
```
- 종포획률: 종 데이터 `포획률`(0~255, `data/pokemon/`).
- 볼보정: 몬스터볼 1.0, 슈퍼볼 1.5, 하이퍼볼 2.0, 마스터볼 ∞(즉시). 상황형 볼(다이브·네트 등)은 조건 충족 시 3.5.
- 상태보정: 잠듦/얼음 2.0, 마비/독/화상 1.5, 없음 1.0.

## 흔들림 판정

```
a ≥ 255 → 즉시 포획
아니면 b = floor( 65536 / (255 / a)^0.1875 )
4회 반복: randint(0,65535) < b 이면 흔들림 성공, 아니면 그 횟수만큼 흔들리고 탈출
4회 모두 성공 → 포획
```
- 검증 예: 최대HP120·현재HP8·포획률45·하이퍼볼2.0·잠듦2.0 → a=172, 4회 성공 포획(시드555 재현).

## 포획 성공 후

- 개체 스키마(IV/EV/성격/현재기술/포획정보)를 확정해 세이브 파티(여유 시) 또는 박스에 추가.
- `도감_진행.잡은_종`/`본_종` 갱신. IV는 야생이면 `randint(0,31)` ×6, 성격은 25종 중 `randint`.

## 규제

- 전설/환상(`희귀도`)은 법·시나리오 플래그를 만족해야 포획 시도 가능(lore·regions 연동). 볼 탈출률·포획률이 매우 낮게 설정된다.
