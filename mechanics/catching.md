# 포획 규칙

> **상태: Phase 3에서 완성·검증.** 아래는 확정 골격(본가 흔들림 판정 기반).

## 포획률 a 계산

```
a = floor( (3·최대HP − 2·현재HP) · 종포획률 · 볼보정 · 상태보정 / (3·최대HP) )
```
- 종포획률: 종 데이터 `포획률`(0~255).
- 볼보정: 몬스터볼 1.0, 슈퍼볼 1.5, 하이퍼볼 2.0, 그 외 상황형 볼은 조건부.
- 상태보정: 잠듦/얼음 2.0, 마비/독/화상 1.5, 없음 1.0.

## 흔들림 판정

- `a ≥ 255`면 즉시 포획.
- 아니면 흔들림 임계값 `b = floor( 65536 / (255/a)^0.1875 )` 계산.
- 4회 `randint(0,65535) < b` 판정 모두 성공 → 포획. 중간 실패 시 그 횟수만큼 흔들리고 탈출.
- 모든 굴림은 PRNG(seed,counter)로 굴려 재현 가능.

## 규제

- 전설/환상은 법·시나리오 조건을 만족해야 시도 가능(lore/regions와 연동).
- 포획 성공 시 개체 스키마(IV/EV/성격/포획정보)를 확정해 세이브 박스/파티에 추가, 도감 갱신.
