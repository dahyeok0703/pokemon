# 현실 지구 2035 — 포켓몬 텍스트 RPG

> 2026년, 포켓몬이 **진짜 지구**에 처음 나타났다. 9년 뒤 — 2035년, 인간과 포켓몬의 공존은 이미 일상이다.
> 당신은 이 세계에 막 발을 들인 신인 트레이너다.

이 저장소는 **두 가지 방식**으로 플레이할 수 있습니다.

---

## 🅰️ 브라우저에서 바로 플레이 (StackBlitz / 자체 실행 웹게임)

AI 없이 브라우저에서 완전히 돌아가는 텍스트 RPG입니다. 데이터(1025종·919기술·타입표·520대회)와
검증된 전투 공식을 그대로 사용합니다.

### StackBlitz에서 열기
- 기본 브랜치: `https://stackblitz.com/github/dahyeok0703/pokemon`
- 이 기능 브랜치: `https://stackblitz.com/github/dahyeok0703/pokemon/tree/claude/quirky-maxwell-ObuIk`

열면 자동으로 `npm install` 후 `npm run dev`가 실행되고, 미리보기 창에서 바로 플레이됩니다.

### 로컬에서 실행
```bash
npm install
npm run dev      # http://localhost:5173
```

### 할 수 있는 것
- **스타터 자유 선택**: 전 세대 어떤 포켓몬이든(전설·환상 제외) 검색/세대/타입으로 골라 시작.
  고른 포켓몬에 맞춰 **주인공 배경 스토리**와 출신지가 부여됨.
- **전 지구 탐험**: 30여 개 실제 지역(도쿄·후지산·아마존·사하라·알프스·남극·태평양 등)을
  대륙→지역으로 이동하며 누빈다. 지역마다 기후·출현 타입·레벨대가 다름.
- **다양한 탐험 방식**: 걷기 · 낚시 · 서핑 · 동굴 · 등산 · 야간 · 잠복(희귀·배회 전설 노리기) +
  주변 정찰(돈·아이템·떠돌이 트레이너 랜덤 이벤트). **낮/밤 전환**으로 출현종 변화.
- **이미지**: 모든 포켓몬 공식 아트워크/스프라이트 표시(배틀·조우·파티·도감).
- **전투**: 본가 공식(데미지·명중·급소·타입상성·자속) 기반, 계산 근거 투명 출력. 포켓몬을
  잡거나 쓰러뜨리면 **돈 획득**. 경험치·레벨업·**진화**, 파티(최대 6)·박스.
- **도감**: 전 1025종을 세대별 그리드로 전부 표시 — 못 본 종은 반투명, **직접 본 종은 선명하게**,
  포획한 종은 ✅. 클릭하면 종족값·출현지 상세.
- **대회**: 명성·면허 자격 충족 시 출전 → 라운드별 트레이너전 → 우승 시 상금·명성·면허 승급.
- **세이브**: 브라우저 `localStorage`에 자동 저장 (제목 화면 "이어하기")

> 웹게임은 결정론 엔진(전투·포획)이 핵심이며, 자유로운 서사 즉흥성은 아래 GM 모드 쪽이 강합니다.

## 🅱️ Claude Code로 플레이 (AI 게임 마스터)

Claude Code(CLI/웹)에서 이 폴더를 열고 **"새 게임 시작"** 또는 **"이어하기"** 라고 말하면,
Claude가 `CLAUDE.md`(GM 규칙서)와 `saves/player.json`을 읽어 **게임 마스터**로서 자유롭게 진행합니다.
자유 입력·즉흥 서사·NPC 연기가 가능하며, 전투 수치는 동일한 결정론 공식으로 계산됩니다.

| 말 | 동작 |
|---|---|
| `상태` / `파티` | 현재 상태 |
| `도감` / `달력` | 도감 진행 / 대회 일정 |
| `수치 보여줘` | 직전 전투 계산 근거 |
| `세이브` | 즉시 저장 |
| 자유 문장 | 하고 싶은 행동을 그냥 말하세요 |

## 공통 규칙

- 전 세대 모든 포켓몬 + 전설/환상 등장
- 강화는 **메가진화**·**거다이맥스** 두 가지뿐 (다이맥스/Z기술/테라스탈 없음)
- 전투는 **결정론적 수치 계산** — 같은 상황·같은 시드면 항상 같은 결과
- 포켓몬은 실제 지리·기후에 매핑되어 출현, 전 세계 520개 대회가 달력에 따라 열림

## 폴더 구조 (요약)

| 경로 | 내용 |
|---|---|
| `src/` | 브라우저 웹게임(Vite + TypeScript) |
| `data/` | 포켓몬·기술·타입표·대회·NPC·세계관 데이터 (웹게임과 GM이 공유) |
| `mechanics/` | 전투·포획·육성·메가·거다이맥스 규칙(공식) |
| `tools/` | 데이터 생성·검증 스크립트(Python) |
| `CLAUDE.md` | AI GM 운영 규칙서 |
| `saves/` | GM 모드 세이브(JSON) |

자세한 내용은 `CLAUDE.md`의 "파일 지도"를 참고하세요.
