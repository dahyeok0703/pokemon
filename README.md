# 현실 지구 2035 — 포켓몬 텍스트 RPG

이 폴더는 **Claude Code만으로 동작하는 텍스트 기반 포켓몬 RPG**입니다.
별도의 앱·서버·실행 환경이 필요 없습니다. 이 폴더에서 Claude Code를 열고 말만 걸면 됩니다.

## 어떻게 플레이하나요?

이 폴더에서 Claude Code를 연 뒤, 아래처럼 말하세요.

- 처음 시작: **"새 게임 시작"** 또는 **"시작하자"**
- 이어서 하기: **"이어하기"**

그러면 GM(게임 마스터)인 Claude가 `CLAUDE.md`(운영 규칙)와 `saves/player.json`(저장 데이터)을 읽고
마지막 장면에서 이야기를 이어갑니다.

## 세계관 한 줄 요약

> 2026년, 포켓몬이 **진짜 지구**에 처음 나타났다. 그로부터 9년 — 2035년, 인간과 포켓몬의 공존은 이미 일상이다.
> 당신은 이 세계에 막 발을 들인 신인 트레이너다.

화려한 판타지가 아니라 **"현실에 포켓몬이 실제로 살게 됐다면?"** 이라는 사실적인 세계입니다.
포켓몬은 실제 국가·도시·기후·지형에 따라 출현하고, 전 세계에 약 500개의 대회가 달력에 따라 열립니다.

## 플레이 중 쓸 수 있는 말들

| 말 | 동작 |
|---|---|
| `상태` / `파티` | 현재 플레이어·파티 상태 보기 |
| `도감` | 포켓몬 도감 진행도 |
| `달력` | 다가오는 대회 일정 |
| `수치 보여줘` | 직전 전투의 데미지·확률 계산 근거 설명 |
| `세이브` | 현재 상태 즉시 저장 |
| 자유 문장 | 그냥 하고 싶은 행동을 말로 하세요 (예: "동쪽 해안으로 가본다") |

## 규칙 특징

- 전 세대 모든 포켓몬 + 전설/환상 등장
- 강화 메커니즘은 **메가진화**와 **거다이맥스** 두 가지뿐 (다이맥스/Z기술/테라스탈 없음)
- 전투는 **본가 공식 기반의 결정론적 수치 계산** — 같은 상황·같은 시드면 항상 같은 결과. GM은 감으로 판정하지 않습니다.
- 모든 진행 상태는 `saves/player.json`에 저장되어 세션이 끊겨도 보존됩니다.

이 폴더의 데이터·규칙 파일을 직접 편집해 세계를 확장할 수도 있습니다.
